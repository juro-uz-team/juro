# Reopen citations from pinned evidence

Citation Evidence Receipts retain the immutable object identity, language, article identity and hashes of the evidence actually used in a Legal Answer. Opening a citation reauthenticates those bytes and the resulting text after the conversation ownership check; it does not resolve the current release or substitute a later article.

This preserves source-text retention limits while allowing complete evidence to be reopened. Existing citations use a matching legacy content hash when available, otherwise their saved excerpt. A missing receipt object leaves an explicitly incomplete view, never a newly fetched revision presented as the original citation.
