# Self-host application storage and runtime

Status: accepted for the isolated self-hosted version - 2026-09-23

JURO will preserve application behavior while replacing Cloudflare application services with a self-hosted runtime and PostgreSQL with pgvector. This trades managed infrastructure for operational ownership to remove Cloudflare runtime dependencies; domain management remains outside this migration. Development takes place on a dedicated branch and separate server checkout, with read-only access to existing Cloudflare resources and no production cutover.

For this version, this decision supersedes the Cloudflare-specific storage and execution choices in ADRs 0006 and 0008. Their retrieval and evidence contracts remain: preserve both candidate lanes, immutable release identities, reusable embeddings, complete mappings, and hash-verified source evidence. The data archive must include all existing official legal corpus material and its embeddings, including historical and inactive material, with test accounts instead of production users and private uploads; existing applied migrations remain unchanged, with a separate PostgreSQL migration history. Imported collections remain unavailable to retrieval until source inventory, original embedding values, metadata, release mappings, and evidence hashes have been reconciled. Downloading historical or inactive material never changes its eligibility.

PostgreSQL is the primary database and pgvector stores embeddings. The storage design may change substantially to remove Cloudflare dependencies; additional services such as Redis require a concrete need. Large binary evidence and search artifacts use immutable SHA-256-addressed local files, with object identity and metadata in PostgreSQL. PostgreSQL also owns durable jobs, leases, retries, and dead letters; no Redis service is required by the current workload. Native Node services run the platform, website, admin console, and jobs, with local ClamAV and document conversion tools.

The initial services bind only to loopback for SSH access. Password, session, MFA, ownership and tenant checks remain enforced; a private-environment challenge policy replaces Turnstile. Email is captured locally, live payments and automatic ingestion remain disabled, and existing AI providers are called directly. PostgreSQL backups use a consistent snapshot with immutable object references and copied public assets; restore validation checks database counts and file hashes. See [self-hosted operations](../self-hosted-operations.md) for deployment and recovery procedures.

The authorized storage migration also supersedes ADR 0014's requirement to retain the existing database schema and storage interfaces only where necessary for the self-hosted backend. Its answer-quality, existing-data compatibility, and immutable applied-migration requirements remain in force.
